Documentation WebSocket (Socket.IO)

Adresse de connexion : ws://localhost:3000

Événements Émis (Client ➔ Serveur)

Événement Payload Description
join_group "NomDuGroupe" (String) Rejoint un canal de discussion spécifique.
send_message { user, text, group } (Object) Envoie un message instantané dans un groupe.

Événements Reçus (Serveur ➔ Client)

Événement Payload Description
receive_message { user, text, group } (Object) Diffusion d'un nouveau message aux membres du groupe.
